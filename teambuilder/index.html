세션 만들기 (진행자)

❓ 카톡 투표 캡처 방법
  1. 카톡 투표 메시지 → 투표 현황 → 항목별 탭을 엽니다.
  2. 갤럭시: 캡처(전원+볼륨↓) 후 하단 툴바의 스크롤 캡처(↓↓ 아이콘)를 눌러 명단 끝까지 내려 한 장으로 저장합니다.
  3. 아이폰: 카톡 화면은 '전체 페이지' 캡처가 지원되지 않아요. 화면을 조금씩 내리며 여러 장 캡처한 뒤, 업로드할 때 한꺼번에 선택하세요. 겹치는 이름은 자동으로 합쳐집니다.
  4. 📷 캡처 파일 업로드로 올리거나, 이미지를 복사해 📋 붙여넣기 하세요.
  • 명단이 이름/정보1/정보2 형식이어도 앞의 이름만 사용합니다.
  • 인식 오류가 있을 수 있으니 추출 후 인원수와 이름을 꼭 확인하세요.

진행자 기기가 세션 서버 역할을 합니다. 드래프트가 끝날 때까지 이 화면을 닫지 마세요. (새로고침 시 같은 코드로 자동 복구)
